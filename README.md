# Konkoin — Landing Page

Landing page untuk **Konkoin**, aset digital (cryptocurrency) bertema olahraga yang dikembangkan dalam rangka kegiatan **PON (Pekan Olahraga Nasional) KONI tahun 2023 di Aceh**.

## Tentang proyek

Konkoin adalah koin kripto olahraga pertama di Indonesia. Proyek ini berupa **landing page** yang memperkenalkan asset coin tersebut kepada publik: visi dukungan terhadap olahraga nasional, roadmap, manfaat kepemilikan, serta akses unduh aplikasi.

Landing page ini dibuat sebagai media informasi dan promosi asset crypto Konkoin yang terkait kegiatan olahraga nasional (PON) yang diselenggarakan KONI di Aceh pada tahun 2023.

## Fitur halaman

- Hero / banner utama
- Pengenalan Konkoin
- Roadmap
- Manfaat / tokenomics visual
- Section unduh aplikasi (App Store)
- Latest news & media partner
- Navigasi mobile (bottom navbar)

## Tech stack

- React (Create React App / `react-scripts`)
- React Router
- Bootstrap
- pnpm

## Menjalankan lokal

```bash
pnpm install
pnpm start_linux
```

Aplikasi berjalan di port `3008`.

Build produksi:

```bash
pnpm build
```

## Catatan

Proyek ini merupakan portfolio frontend untuk landing page asset coin crypto Konkoin dalam konteks kegiatan olahraga nasional PON KONI 2023 (Aceh).
